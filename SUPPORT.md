# Support Sqlitos

## Documentation et produit

Commencez par le [site officiel](https://sqlitos.vercel.app) pour découvrir le produit et les informations publiques à jour.

## Besoin d’aide ?

Ouvrez une issue si votre question peut aider d’autres utilisateurs. Pour accélérer le diagnostic, indiquez :

- la version de Sqlitos ;
- votre système d’exploitation ;
- le type de connexion utilisé (fichier local ou serveur distant) ;
- le comportement attendu et le comportement observé.

## Informations sensibles

N’ajoutez jamais de base réelle, mot de passe, jeton, clé API ou donnée client dans une issue. Pour une vulnérabilité, suivez [SECURITY.md](SECURITY.md).
