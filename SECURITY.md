# Politique de sécurité

La sécurité de Sqlitos est traitée avec sérieux. Si vous pensez avoir identifié une vulnérabilité, ne publiez pas son détail dans une issue publique.

## Signaler une vulnérabilité

Utilisez la fonctionnalité **Private vulnerability reporting** de GitHub si elle est activée sur ce dépôt. Sinon, contactez l’organisation qui publie Sqlitos par le canal privé affiché sur son profil GitHub.

Incluez, lorsque c’est possible :

- une description claire de l’impact ;
- les versions concernées ;
- des étapes de reproduction minimales ;
- une preuve de concept non destructive ;
- toute recommandation de correction.

Nous accuserons réception, évaluerons le problème et coordonnerons une correction avant toute divulgation publique.

## Périmètre

Les signalements peuvent notamment concerner l’application desktop, les installateurs publiés, le serveur distant optionnel et les services cloud associés. Les tests doivent rester légaux, proportionnés et ne jamais viser des données ou systèmes tiers sans autorisation.
