
# Contribuer à la vitrine Sqlitos

Ce dépôt ne distribue pas le code source de l’application. Les contributions portent donc sur la documentation publique, les notes de version, les exemples non sensibles et les retours produit.

## Avant d’ouvrir une issue

- Vérifiez qu’un sujet similaire n’existe pas déjà.
- N’incluez ni base de données réelle, ni mot de passe, ni clé API.
- Pour un bug, indiquez la version de l’application, le système d’exploitation et les étapes de reproduction.

## Proposer une amélioration

Les demandes les plus utiles décrivent le problème à résoudre, les utilisateurs concernés et le résultat attendu plutôt qu’une implémentation imposée.

## Proposer une modification documentaire

Les pull requests sont bienvenues pour corriger une information, clarifier un parcours ou améliorer la traduction. Gardez les changements ciblés et n’ajoutez pas d’informations produit non vérifiées.
